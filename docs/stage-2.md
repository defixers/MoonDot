所有业务写入仍通过受信任窗口、主 frame、白名单 IPC 与严格 Zod 入参校验；渲染进程不能访问 SQLite、Node 或任意路径。服务端校验项目归属、子任务层级与归档状态，不能通过直接调用 IPC 绕过只读限制。

## 规则与数据

- 项目进度 = 阶段权重加权完成度，四舍五入为整数百分比。存在有效顶层任务时，阶段完成度为完成数 / 总数；取消和删除任务排除，子任务不重复计权。没有有效顶层任务时，手动待办/进行中/完成分别计 0/50/100%。未关联阶段的任务不计入阶段进度。
- 未关闭项目超过项目截止日标为“已逾期”；有逾期未完成任务，或距截止日不超过 7 天且进度低于 70%，标为“有风险”。使用本机日历日期判断，已完成/归档项目不提示风险。
- 模板权重按总和归一化为 100%。编辑或删除模板不会改动已有项目的阶段。至少保留一个模板；删除默认模板会清空默认选择。
- 排序仅更新被移动任务；恢复已删除任务时放到相应状态末尾，避免旧排序位置被新任务占用。恢复父任务只恢复同批删除的子任务，之前单独删除的子任务仍保持删除。
- 项目与任务软删除数据至少保留 30 天，不自动永久清除。项目回收站提供主动彻底删除，必须输入完整项目名；项目、任务、备注及动态一起删除，不可撤销。单独删除备注也是永久操作。
- 撤销令牌仅在当前进程中有效，服务端限制 5 秒。其后的业务写入使旧撤销失效，避免覆盖新编辑；超时后使用回收站恢复。重启不恢复撤销令牌。
- 搜索用 FTS5 trigram 处理至少 3 个字符的词组，1–2 字符用转义后的 LIKE，支持中文短词与字面 `%`、`_`。按标题前缀、标题包含、正文匹配排序，最多返回 50 条；软删除项目及任务的备注不出现在结果里。
- 封面支持 PNG/JPEG/WebP，界面限制 2 MB，以 data URL 存入 SQLite。本阶段不引入音频 CAS 或任意文件路径读取。

schema v2 新增 `stage_templates`、`projects`、`project_stages`、`tasks`、`notes`、`activity_logs` 和 `search_index`。搜索索引由事务内触发器同步，更新/删除不会遗留旧词条。`0001-foundation` 未修改；新增 `0002-projects`，沿用 SQL 校验和、升级前在线快照、事务迁移与拒绝降级。v1 设置与已有显示名保留。

## 演示与验收

1. 执行 `pnpm.cmd dev`，打开“项目”，创建“夏日回声计划”，选择单曲模板，可取消自动生成初始任务。
2. 在概览中将无任务的“企划”阶段设为已完成，确认项目进度为 5%。
3. 在“任务”中新建“录制主唱”，关联“录音”，拖到已完成或选择状态；确认项目进度变为 25%。添加子任务与任务备注，验证子任务不重复计权。
4. 按 Ctrl/Cmd + K 搜索任务备注，点击进入任务详情；在“我的任务”按项目筛选，再切换列表。
5. 编辑阶段模板，创建新项目核对流程；确认旧项目阶段保持不变。在设置中保存默认模板与视图。
6. 退出并重新启动，确认项目、任务、备注、阶段进度和偏好保留。
7. 归档项目，确认编辑入口消失；撤销归档，再删除项目并从回收站恢复。彻底删除仅在测试项目上验证。

自动化入口：`pnpm.cmd check`。单元/集成测试覆盖 v1→v2 升级与重开、模板复制、进度、归档与跨项目校验、子树恢复、恢复排序、删除批次、中文/短词搜索、索引同步、撤销过期/后续编辑冲突及设置校验。Electron 测试覆盖真实界面创建、编辑、备注、搜索跳转、重启恢复、归档撤销、回收站、项目筛选与表格视图；基础启动、IPC、窗口与缩放测试继续保留。

- 阶段状态显示调整后，重新通过生产构建和 2 项项目界面测试。
- 已检查项目概览、看板与表格截图；基础壳的 200% 缩放测试通过。测试数据均使用独立临时目录。

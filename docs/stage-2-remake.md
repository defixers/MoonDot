# 第二阶段重做详情

## 调整原因与方向

项目管理系统界面过于臃肿，且不符合实际生产需求，需要大规模调整创建项目等功能，其任务、动态和阶段模板功能彻底删除，不需要项目归档功能，添加项目回收站，保留七天内删除的项目，允许用户提前自行删除项目回收站内容，项目回收站只清理项目记录，不自动删除磁盘文件；恢复项目时重新关联原目录，恢复项目时重新关联原目录，目录不可用时提示重新定位。七天按删除时刻起算，应用运行期间检查，关闭期间到期的记录在下次启动时清理

## 核心任务

### 1. 创建项目

- 用户使用引导式创建项目
- 引导式创建可以逐步引导用户创建项目，避免一次性信息过多导致填写混乱
- 项目类型分为单曲、专辑、EP，类型仅供用户识别，不影响项目内部的歌曲数量和人员划分等
- 引导式创建如下方顺序：
  1. 确定项目名称、项目封面和项目备注（名称必填，封面和备注选填）
  2. 选择项目类型：单曲、专辑、EP（必填）
  3. 确定项目的各个工位，分为如下五个阶段，同一页面内五个可折叠区域，划分好每一个部分的区域，不需要填写歌曲的具体信息
     - 策划与统筹：企划、制作人、音乐总监、统筹
     - 创作：作曲、编曲、作词
     - 录音与演奏：歌手（演唱者）、乐手（演奏者）、录音工程师
     - 后期制作：音频编辑、混音工程师、母带工程师
     - 视觉与发行：艺术总监、MV/PV导演、宣传
  4. 确定项目上述五个阶段的交付时间和项目的截止日期，精确到天
  5. 展示全部信息供用户确认，并选择项目存放位置。未选择目录或目录不可写时不能创建；确认成功后创建项目及五个阶段文件夹
- 所有的信息都可以在后续不限次数修改
- 每个岗位允许填写 0 至多名人员；未填写时显示“待添加”。同一人员可以担任多个岗位，也支持多个人员担任同一岗位，人员仅为文本记录，不关联账号
- 五个阶段分区折叠，默认显示已填写人数，第三步与第四步提供“暂不填写，下一步”选项

### 2. 项目选择和预览

- 新建项目默认“未完成”，由用户手动标记“已完成”，允许重新打开。完成后仍可编辑信息和管理文件，不因修改内容自动改变状态。截止日期不自动决定项目是否完成
- 每个项目的对应卡片只显示封面、名称、类型、创建时间、截止时间、状态，且整个卡片都可以点击

### 3. 项目详情

- 详情内部将项目划分为五个阶段：策划与统筹、创作、录音与演奏、后期制作、视觉与发行
- 每个阶段都有自己的文件夹，用来专门存放该阶段的所有文件，详情如下：
  - 项目文件根目录由用户决定，用户选择存放位置，软件在其中创建独立项目文件夹，并建立固定五个阶段子文件夹。已有同名目录时不覆盖；禁止两个项目共用或嵌套使用同一项目目录。修改项目名称不会自动重命名磁盘目录
  - 软件内选择/拖入以添加文件
  - 导入默认为复制操作
  - 支持子文件夹。同一文件夹内不允许重名，不同文件夹允许重名。导入遇到冲突时提供“跳过”或“保留两份并自动编号”，不直接覆盖。批量导入显示进度和失败项，可取消；失败或取消不留下被当作完整文件的半成品。支持软件内重命名/删除，删除优先移入系统回收站，不支持时提示用户，不直接静默永久删除。支持拖入文件夹，允许保留目录结构导入
  - 外部新增、修改或删除文件后，软件自动刷新。仅在项目文件页面可见时，每十秒检查当前打开的目录，并提供手动刷新；不每十秒递归扫描所有项目文件
  - 磁盘未连接、目录被移动、无写入权限进行提示
  - 预览本阶段仅指图标与文件列表
  - 显示文件修改时间与加入项目时间。软件导入的文件以导入成功时间为加入时间；外部放入的文件以软件首次发现时间为加入时间，后续刷新不重置
  - 每个阶段提供“在资源管理器 / Finder 中打开”入口；文件提供“在文件夹中显示”操作
  - 重新定位只关联已有项目目录，不自动搬迁文件。五个固定阶段目录不能在软件内重命名或删除，其内部文件和子文件夹可以管理
- 权重机制彻底删除
- 每个阶段旁边标记其交付日期，不需要用户选择项目进度

## 其他

- 删除待办、进度和相关风险统计，保留最近项目
- 保留项目名称、项目备注、人员搜索
- 移除表格及默认视图设置
- 艺人、流派、BPM、调性、标签、色标移除
- 项目备注为一个可编辑文本字段
- 移除业务动态页面，用于排错的本地运行日志仍保留
- 保留本机显示名与窗口状态；移除任务视图、项目表格视图和默认阶段模板等已废弃设置
- 本次重做不提供旧业务数据迁移。新版使用独立数据库，旧数据库保留，不自动清空或覆盖；仅继承本机显示名与窗口状态

## 验收

- 人员和日期全部跳过仍能创建；返回上一步不丢输入
- 项目信息、岗位人员、日期和目录关联在重启后保留
- 完成、重新打开、删除、恢复和七天清理行为正确
- 文件导入、重名处理、外部变动刷新及磁盘断开提示正确
- 创建目录或导入文件失败时，不留下错误记录
- 界面、设置及搜索中不再残留任务、模板、归档和进度功能
